# Blog Project

A simple responsive blog web application built with Node.js, Express.js, and EJS.

## Features

* Create blog posts
* View all posts
* Read individual posts
* Edit posts
* Delete posts
* Basic server-side validation
* Responsive styling

## Tech Stack

* Node.js
* Express.js
* EJS
* HTML
* CSS

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/gaureehatkar/blog-project.git
```

2. Move into the project folder:

```bash
cd blog-project
```

3. Install dependencies:

```bash
npm install
```

4. Start the server:

```bash
node index.js
```

5. Open the application in your browser:

```text
http://localhost:3000
```

## Note

Posts are stored in memory, so they are reset whenever the server restarts. This project does not use a database.
